**# JEE Leader Downloader Bot

High-performance video downloader and Telegram uploader configured for Heroku Container Stack.

## Deploy Directly to Heroku

Click the deploy button to spin up the worker on Heroku using Docker:

[![Deploy](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/rank-wallah/LN-UPLOADER)

### Deployment Instructions:
1. Create a GitHub repository and add all files from this directory (`requirements.txt`, `app.json`, `Dockerfile`, `heroku.yml`, `Procfile`, `allen2.py`, `physics.json`, `chemistry.json`, `maths.json`, `README.md`).
2. Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPO_NAME` in `app.json` and `README.md` with your repository details.
3. Click the Deploy button above. Fill in your environment variables on the Heroku dashboard and deploy.**
